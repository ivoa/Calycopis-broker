        Example for the MD5UM calculator.

    User has two options.
    a) If they already know which platform they want to run the task on,
    they can submit the request to the `direct` execution endpoint.
    The service will validate the request and assuming it is able to perform
    the requested task, it will schedule the task for execution.
    If it is not able to execute the task, the service will return an
    error response containing messages describing why the task
    could not be executed.

    b) The more flexible option is to submit the request to the
    execution `request` endpoint.
    The service will validate the request and assuming it is able to perform
    the requested task, it will respond with a positive response containing
    one or more offers.
    The user then has the choice of which offer to accept.
    The user, or their agent, can send requests to multiple platforms,
    compare the resulting offers, and decide which one best represents
    what they want.
