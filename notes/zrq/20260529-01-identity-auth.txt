  Owner-based authorization in SessionsApiDelegateImpl.executionUpdatePost():
  • Before applying an update, the handler now looks up the session and checks ownership
  • If the session has an owner and the caller's identity doesn't match, returns 403 FORBIDDEN
  • If the session has no owner (legacy/anonymous), or the caller is anonymous, the update proceeds (graceful degradation for the
     transition period)

  Configuration:
  • The OIDC issuer URI is externalized via spring.security.oauth2.resourceserver.jwt.issuer-uri (or OIDC_ISSUER_URI env var)
  • When no issuer is configured, the service operates with HTTP Basic auth only
