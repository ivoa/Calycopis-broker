# Create out database config.
#[root@calycopis-dev]

    mkdir /etc/calycopis

    cat > /etc/calycopis/database.yaml << EOF
spring:
    datasource:
        url: jdbc:postgresql://postgresql:5432/calycopis
        username: $(pwgen 32 1)
        password: $(pwgen 32 1)
        driverClassName: org.postgresql.Driver
        initialize: true
EOF

        --expose 5432 \

        --env "POSTGRES_USER=$(yq '.spring.datasource.username' /etc/calycopis/database.yaml)" \
        --env "POSTGRES_PASSWORD=$(yq '.spring.datasource.password' /etc/calycopis/database.yaml)" \

  Authentication and Identity Implementation Plan

  This plan adds authentication and identity tracking to the Calycopis broker, implementing Spring Security with both OIDC (JWT) and
  local (HTTP Basic) authentication, plus an IdentityEntity ownership model for all components.

  Phases:

  1. Phase A — Create Identity model, add nullable owner field to ComponentEntity, create repository and factory

  3. Phase C — Modify factory interfaces to accept IdentityEntity, update delegates to resolve and pass identity, propagate owner
     through all entity creation
  4. Phase D — Enable authentication enforcement on POST endpoints, add owner-based authorization checks
